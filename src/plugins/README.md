# Coinbase Agents

Coinbase workflows for portable Agent Plugins clients and native harness integrations.

Start with the `coinbase` skill to choose a product, then load that product's entry skill for setup and workflows. This package includes Coinbase for Agents: its remote MCP server uses client-managed OAuth, and local CLI execution requires a separately installed and configured Coinbase CLI.

Installation and authentication do not authorize financial actions. Confirm each trade, transfer, conversion, or x402 budget before execution.

Source and release documentation: https://github.com/coinbase/agents
